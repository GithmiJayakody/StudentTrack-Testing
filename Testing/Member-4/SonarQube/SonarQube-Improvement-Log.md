## 4. Code Improvements and Verification

The identified security issues were addressed through changes to the backend application configuration.

### 4.1 IMP-01 – Restrict CORS Configuration

**Original Code:**

```javascript
app.use(cors());
```

**Implemented Code:**

```javascript
const allowedOrigin = 'http://localhost:5174';

app.use(cors({
  origin: (origin, callback) => {
    if (!origin || origin === allowedOrigin) {
      callback(null, true);
    } else {
      callback(null, false);
    }
  },
}));
```

**Reason for Improvement:**

The CORS configuration was updated to allow requests from the intended StudentTrack frontend origin rather than allowing all origins.

**Testing and Verification:**

- A Jest test verified that the authorized frontend origin was allowed.
- A Jest test verified that an unauthorized origin was not returned as an allowed origin.
- The CORS configuration was updated and the test suite was executed successfully.

### 4.2 IMP-02 – Disable Express Version Disclosure

**Implemented Code:**

```javascript
app.disable('x-powered-by');
```

**Reason for Improvement:**

Disabling the `X-Powered-By` header prevents the application from unnecessarily disclosing Express framework information in HTTP responses.

**Testing and Verification:**

A Jest test verified that the `X-Powered-By` response header was absent.

## 6. Recommendations

Based on the SonarQube findings, the following improvements are recommended for future development:

1. **Improve Promise Handling:** Implement appropriate error handling using `try/catch` blocks and `.catch()` methods to prevent unhandled promise rejections.

2. **Improve Form Accessibility:** Associate form labels with their corresponding input elements to improve accessibility and usability.

3. **Use Semantic HTML Elements:** Use appropriate native HTML elements such as `<button>` and `<a>` instead of non-native interactive elements to improve accessibility and keyboard navigation.

4. **Improve Security Configuration:** Continue reviewing CORS settings, framework information disclosure, and hardcoded IP address configurations.

5. **Increase Test Coverage:** Develop additional automated tests for important backend and frontend functionalities to improve overall code coverage.
